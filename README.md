# Chrome Tab Cleaner

<p align="center">
  <img src="icons/icon128.png" width="96" height="96" alt="Chrome Tab Cleaner">
</p>

一个轻量、纯本地运行的 Chrome 标签页整理助手。它会在你打开重复网页时及时
提醒，由你决定关闭旧标签，或保留并自动分组；同时记录已稳定加载的页面，方便
之后按标题找回。

无需账号、无需服务器、无需构建，也不会擅自关闭正在使用的标签页。

## 为什么需要它

浏览器标签页通常不是一次变乱的，而是在日常工作中慢慢堆积：

- 从聊天、邮件和搜索结果反复打开同一个页面，却没有意识到它已经存在。
- 同一系统的不同入口散落在多个窗口和分组里，越用越难定位。
- 想清理重复标签，又担心关闭错误页面、丢失固定标签或破坏现有分组。
- 几天前访问过一个有用页面，只记得标题关键词，却找不到原链接。
- 传统“一键清理”工具过于激进，缺少预览和最终确认。

Chrome Tab Cleaner 把清理动作放在重复发生的那一刻：先识别、再展示旧页面，
最后由你选择如何处理。它减少无效标签，又保留对浏览上下文的控制权。

## 能带来什么

| 痛点 | Chrome Tab Cleaner 的处理方式 |
| --- | --- |
| 重复页面不断累积 | 页面稳定加载后自动检测，并在工具栏显示待处理数量 |
| URL 参数不同导致漏判 | 忽略锚点和常见追踪参数，并规范化查询参数顺序 |
| 同一业务站点有多个入口 | 可按“同一网站”匹配，忽略路径和常见顶级域名差异 |
| 不确定哪个标签该关闭 | 显示旧页面标题、URL 和缩略图，再由用户确认 |
| 标签组被清理动作打乱 | 优先复用原分组，保留分组颜色和折叠状态 |
| 历史页面难以找回 | 本地记录标题、URL、打开时间和停留时长，支持标题搜索 |

## 核心能力

### 智能识别重复标签

- **同一网站模式**：适合后台系统、文档站和内容平台。站点主体一致即可识别，
  路径、参数以及 `.com`、`.net` 等顶级域名可以不同。
- **同一页面模式**：按规范化后的完整 URL 精确匹配。
- 自动忽略 URL 锚点、`utm_*`、`gclid`、`fbclid` 等追踪参数。
- 查询参数顺序不同，仍可判断为同一页面。
- 支持域名白名单，规则同时覆盖对应子域名。

### 由你决定，而不是后台擅自关闭

发现重复后，紧凑弹窗只提供两个明确选择：

1. **关闭旧标签**：保留刚打开的新标签；若旧标签属于某个分组，会先将新标签
   移入原分组，再关闭旧标签。
2. **保留并分组**：保留两个标签，并创建或复用标签组。组名取域名最左侧部分，
   例如 `issues.example.com` 会使用 `issues`。

存在多个旧重复标签时，会优先处理最近访问的旧标签。固定标签始终优先保留。

### 不打断现有工作流

- 旧标签位于折叠分组时，不会为了生成缩略图而展开分组。
- 复用已有标签组时，不修改组的颜色和折叠状态。
- 同一地址在用户选择保留后不会反复提醒。
- 可清除当前窗口的全部待办，而不关闭任何标签。
- 可扫描并整理安装扩展前已经存在的重复标签。

### 可搜索的本地访问记录

页面完成加载并稳定后，扩展会记录：

- 网页标题和 URL
- 打开时间
- 停留时长

最多保留最近 2000 条记录，并支持按标题关键词搜索和重新打开。重定向中间页、
未加载完成的页面，以及扩展主动关闭的重复旧标签不会进入历史记录。

## 使用流程

1. 正常浏览网页，无需改变打开链接的习惯。
2. 命中重复时查看旧标签的标题、地址和可用缩略图。
3. 选择“关闭旧标签”或“保留并分组”。
4. 需要集中整理时，点击扩展图标扫描当前窗口。
5. 需要找回页面时，展开“访问记录”并搜索标题关键词。

## 安装

当前版本通过 Chrome 开发者模式安装：

1. 下载或克隆本仓库。
2. 在 Chrome 地址栏打开 `chrome://extensions`。
3. 开启右上角的“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择本项目根目录，并将 Chrome Tab Cleaner 固定到工具栏。

白名单每行填写一个域名，例如：

```text
mail.google.com
docs.example.com
```

## 隐私

Chrome Tab Cleaner 没有服务器端组件，也不会上传浏览数据：

- 设置、统计和访问记录保存在 Chrome 本地存储中。
- 最多 6 张低质量页面缩略图只保存在当前浏览器会话中。
- 仓库不包含使用者的浏览记录、设置或缩略图。
- 所有重复判断和历史搜索都在浏览器本地完成。

扩展需要 `<all_urls>` 主机权限来捕获当前标签页缩略图，不会借此向外部服务发送
页面内容。
