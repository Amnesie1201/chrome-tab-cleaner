# Tab Keeper

一个无需构建、纯本地运行的 Chrome Manifest V3 扩展。新标签页完成导航后，如果当前窗口已经存在相同网页，扩展会提示用户选择关闭旧标签或保留并分组。

## MVP 行为

- 默认开启重复标签提醒，只检查当前 Chrome 窗口。
- 默认按“同一网站”匹配：站点主体一致即视为重复，路径、参数和 `.com`、`.net` 等顶级域名可以不同。
- 可切换为“同一页面”匹配，按归一化后的完整 URL 判断。
- 忽略 URL 锚点，例如 `#comments`。
- 忽略 `utm_*`、`gclid`、`fbclid` 等常见追踪参数。
- 对查询参数排序，参数顺序不同仍可识别为同一网页。
- 固定标签页优先保留。
- 支持域名白名单，规则同时适用于该域名的子域名。
- 自动检查完成导航的标签。
- 存在多个旧重复标签时，优先选择最近访问的旧标签；无法取得访问时间时选择位置最靠后的旧标签。
- 关闭分组内的旧重复标签前，会先把新标签移入原分组。
- 自动弹出的紧凑视图只显示重复页面信息，以及“关闭旧标签”和“保留并分组”两个选项。
- 选择保留时会创建或复用标签组，组名使用域名最左侧标签，例如 `issues.example.com` 使用 `issues`。
- 手动打开完整视图时可一次清除当前窗口的全部待办，不会关闭标签页。
- 决策视图会显示旧标签最近一次处于前台时缓存的页面缩略图。
- 没有缓存时会在弹窗出现前短暂激活旧标签进行捕获，然后恢复新标签。
- 旧标签位于折叠分组时不会为截图激活它，标签组保持折叠。
- 手动打开插件时显示完整的统计、扫描、开关和设置；域名白名单默认折叠。
- 页面完成加载并稳定后会持久化记录 URL、标题、打开时间和停留时长，最多保留最近 2000 条。
- 重定向中间页、未加载完成页面和插件主动关闭的重复标签不会进入访问记录。
- 手动打开插件后可展开“访问记录”，按网页标题关键词筛选并打开历史链接。
- 工具栏徽标显示待处理数量，系统通知仅作为辅助。
- 用户选择保留后，同一标签停留在当前地址期间不会重复提醒。
- 弹窗实时扫描当前窗口，可一键整理安装前已经存在的重复标签。
- 设置、统计和访问记录保存在 Chrome 本地；最多 6 张低质量缩略图仅保留在当前会话内，不发送浏览数据。

## 安装

1. 在 Chrome 地址栏打开 `chrome://extensions`。
2. 开启右上角的“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本项目根目录。

安装后可将 Tab Keeper 固定到工具栏，通过弹窗开关去重或维护白名单。白名单每行填写一个域名，例如：

```text
mail.google.com
docs.example.com
```

## 本地验证

项目没有第三方依赖：

```bash
npm test
npm run check
```

## 隐私

Tab Keeper 不包含服务器端组件，也不会上传浏览数据。访问记录和设置保存在
Chrome 本地存储中，页面缩略图仅保存在当前浏览器会话中。仓库不包含使用者的
浏览记录、设置或缩略图。
